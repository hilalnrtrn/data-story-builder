# Data Story Builder

Data Story Builder is a 20-business-day research prototype / MVP developed during a 2026 software engineering internship.

The system analyzes structured Excel/CSV data, discovers and validates important findings, prioritizes them from a business perspective, and converts validated findings into an explainable and auditable executive data story.

## Core Principle

The LLM is not the analytics engine.

Deterministic and statistical analytics produce validated structured findings. The LLM is used only to transform those findings into an executive narrative.

## Planned Technology Stack

- React
- ASP.NET Core Web API / C#
- Python + FastAPI + pandas + NumPy
- PostgreSQL
- OpenAI API or another explicitly approved LLM provider
- Chart.js
